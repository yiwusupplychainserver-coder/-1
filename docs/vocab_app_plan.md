# 被动学单词 APP 产品规划

## 产品定位
- **产品愿景**：利用手机唤醒时刻的碎片化时间，让用户在不增加额外负担的情况下被动积累英语词汇。
- **目标用户**：英语学习者、职场人士、在校学生，尤其是希望高效利用碎片时间又缺乏主动背词动力的人群。
- **核心卖点**：通过监测手机唤醒状态与使用场景，自动弹出词卡，实现"随时随地，被动记忆"的学习体验。

## 核心功能
1. **唤醒检测与弹窗提醒**
   - 监测手机唤醒/解锁行为，判断用户是否处于玩手机状态。
   - 在合适的时间间隔内弹出单词卡，展示单词释义、例句、语音发音。
   - 提供快速操作（认识/不认识/稍后再看），以优化推送频率与内容。
2. **词汇库与学习路径**
   - 内置分级词汇库，包含高频词、考试词、场景词等类别。
   - 通过记忆曲线算法安排复习，支持自定义添加单词。
3. **学习数据与激励**
   - 统计每日被动学习时长、记忆进度、掌握率。
   - 设置连击天数、成就徽章，增强成就感。
4. **智能干扰控制**
   - 根据用户使用习惯智能调节弹出频率，避免过度打扰。
   - 提供免打扰时段、黑名单应用等设置。

## 版本规划与商业模式
| 版本 | 定价策略 | 功能范围 |
| --- | --- | --- |
| 免费版 | 0 元 | 500 个精选高频词、基础释义与例句、每日被动提醒上限 |
| 基础版 | 订阅：¥XX/月 | 3000 个词、扩展例句与发音、个性化记忆曲线、高级统计报告 |
| Pro 版 | 订阅：¥XX/月 | 解锁全部词库、AI 场景词包、线下/线上活动优先权、每月 1 小时线上英语交流（小班） |

### 收益结构
- 订阅收入（基础版、Pro 版）。
- 线上英语交流课程增值服务。
- 企业合作（面向学校或培训机构提供定制词库）。

## 用户痛点与解决方案
| 用户痛点 | 产品方案 |
| --- | --- |
| 缺乏时间系统背单词 | 唤醒即学，利用碎片化时间，被动记忆 |
| 主动学习动力不足 | 被动弹窗提醒，设置成就与激励，提高参与度 |
| 单词记忆易遗忘 | 记忆曲线算法自动安排复习，跟踪掌握度 |
| 词汇内容单一 | 多维度词库（高频/考试/场景），支持扩展与自定义 |
| 缺少口语练习机会 | Pro 版提供线上交流课，结合实际应用场景 |

## 技术实现要点
- **系统层集成**：调用系统 API 监听唤醒、解锁、前台应用状态。
- **弹窗机制**：实现非侵入式通知/悬浮卡片，确保在关键场景下可快速关闭。
- **后台服务**：词库管理、学习记录、算法推荐、用户订阅管理。
- **隐私与权限**：透明说明采集信息，遵循隐私政策，支持数据导出与删除。

## 用户旅程
1. 下载并注册，选择目标词汇量和学习偏好。
2. 系统检测手机唤醒状态，适时推送单词卡。
3. 用户快速反馈记忆情况，数据上传云端。
4. 通过数据面板查看掌握率和复习计划。
5. Pro 用户预约每月一次的线上英语交流课。

## 营销与增长策略
- **校园与职场合作**：与高校、培训机构、企业合作，提供试用码。
- **内容营销**：制作短视频、社交媒体内容，强调碎片化被动学习特色。
- **裂变激励**：邀请好友解锁额外词包或兑换线上课时。
- **用户反馈循环**：建立社区收集词库建议，快速迭代内容。

## 风险与应对
- **过度打扰导致卸载**：优化提醒算法、提供个性化设置。
- **内容版权问题**：与内容提供商合作或自建原创词库。
- **线上交流体验参差**：严格筛选外教/助教，提供录制回放与客服支持。

## 关键指标
- 日活跃用户（DAU）
- 每日被动学习次数与完成率
- 订阅转化率与续费率
- 线上交流课参与率与满意度

## 实施路线图
1. **MVP 阶段（0-3 个月）**：实现唤醒检测、弹窗词卡、基础词库，发布免费版。
2. **增强阶段（3-6 个月）**：上线订阅体系、扩展词库、记忆曲线、数据面板。
3. **增长阶段（6-12 个月）**：推出 Pro 版特权、线上交流课、企业合作解决方案。

## App 实施方案

### 技术架构
- **客户端**：优先采用 Flutter 或 React Native 构建跨平台界面；需要集成原生插件以监听 Android 的 `ACTION_USER_PRESENT`/`ACTION_SCREEN_ON`、iOS 的 `UIApplicationDidBecomeActiveNotification` 等事件，用于检测唤醒状态。
- **后台服务**：使用云端微服务（如 Node.js + NestJS 或 Python + FastAPI）构建用户、词库、订阅、学习记录等模块；部署在 AWS/GCP/阿里云，配合容器编排（Kubernetes/Serverless）。
- **数据库**：采用 PostgreSQL 存储用户与订阅信息，Redis 缓存热点词库与学习计划，Elasticsearch 实现词汇搜索与推荐。
- **实时与推送**：通过 Firebase Cloud Messaging（FCM）/Apple Push Notification Service（APNS）实现弹窗提醒与后台推送，必要时结合本地通知以保障离线场景。
- **数据分析**：埋点数据上传至数据仓库（BigQuery/Snowflake），使用 Amplitude/Looker 进行漏斗分析与留存追踪。

### 功能模块拆分
1. **登录与用户画像**
   - 支持手机号、邮箱、三方登录（Apple/微信/Google）。
   - 收集学习目标、词汇水平，写入用户画像表，为算法推荐提供输入。
2. **被动词卡弹窗**
   - 原生服务常驻监听唤醒状态，根据干扰控制策略决定是否弹出。
   - 前端呈现词卡组件：单词、音标、释义、例句、操作按钮（认识/模糊/不认识/稍后）。
   - 将用户反馈写入本地缓存，并异步同步到云端。
3. **学习进度与复习计划**
   - 后台依据艾宾浩斯记忆曲线生成复习日程，客户端在合适时间触发提醒。
   - 支持在应用内查看学习日历、完成率、词汇掌握度热力图。
4. **词库与内容管理**
   - CMS 后台支持词条增删改、场景分类、音频上传；可按版本配置词包权限。
   - AI 工具（如 GPT-4o）生成例句、短对话，人工审核后上线。
5. **订阅与支付**
   - 集成 App Store/Google Play 内购，使用 RevenueCat 或自建订阅服务处理账单、试用、优惠券。
   - 后台同步订阅状态，控制功能与词库访问权限。
6. **线上交流课预约**
   - 在 Pro 版中开放预约入口，连接在线会议服务（Zoom/腾讯会议）与 CRM；支持自动发放会议链接、提醒通知。
7. **运营与客服工具**
   - 内置公告中心、FAQ、意见反馈；接入工单系统（如 Zendesk）。
   - 运营可查看用户分层、发送精准推送或邮件营销。

### 项目组织与里程碑
- **团队配置**：产品经理 1、UI/UX 设计 1、前端工程师 2（Flutter/React Native）、后端工程师 2、移动端原生开发 1（处理系统级监听）、算法/数据工程师 1、测试工程师 1、运营 1。
- **开发迭代**：采用 Scrum，每两周一次迭代评审；首个迭代完成唤醒检测与词卡 UI，第二迭代接入词库与记忆算法，第三迭代上线订阅与数据面板。
- **质量保障**：建立自动化测试（单元/UI/集成）、灰度发布与崩溃监控（Sentry/Firebase Crashlytics）。
- **上线流程**：内测（TestFlight/内测渠道）→ 公测（1000 用户）→ 正式版上线；配合营销活动与运营教程。

### 投放与持续优化
- 搭建 A/B 测试框架，优化弹窗频率、词卡展示形式与订阅转化流程。
- 收集用户反馈，快速迭代干扰控制策略与词库内容。
- 数据驱动运营：以 DAU、词卡完成率、订阅转化率、口语课到课率为核心 KPI，按月复盘。
